Kubernetes manifests through to Prometheus alerting and the runbook that gets called

- **CI/CD** — GitHub Actions and Jenkins pipelines covering build, image creation,
  vulnerability scanning, automated validation, smoke tests and rollback verification.
- **Cloud infrastructure** — AWS provisioning (EC2, S3, VPC, RDS, IAM, CloudWatch)
  codified in Terraform and CloudFormation with least-privilege access.
